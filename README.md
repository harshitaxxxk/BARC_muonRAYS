# Cosmic Muon Data Analysis – BARC

## 📌 Overview

This repository contains the data-analysis code developed during my research internship at **Bhabha Atomic Research Centre (BARC)**.

The project focuses on the analysis of **cosmic muon detector data** collected using a **large-area plastic scintillator**. The analysis was carried out to process, study, and visualize experimental detector data using both **C++ and Python**.

The repository contains the analysis code, supporting data, and different implementations developed during the project.

---

## 🎯 Project Objectives

The main objectives of this project were:

- Analyze experimental cosmic-muon detector data
- Process raw detector data for further analysis
- Develop data-analysis routines in C++
- Develop Python-based analysis and visualization tools
- Study characteristics of cosmic-muon events
- Organize and improve the analysis workflow
- Compare and validate different implementations of the analysis code

---

## 🔬 Experimental Background

Cosmic rays continuously interact with the Earth's atmosphere and produce secondary particles, including **muons**.

Muons are highly penetrating particles and can be detected using scintillation-based detector systems.

In this project, data obtained from a **large-area plastic scintillator** was analyzed to study cosmic-muon events.

The analysis involved processing detector measurements and extracting useful information from the experimental data.
